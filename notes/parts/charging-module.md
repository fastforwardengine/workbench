# The charging module

The rechargeable version of the kit adds this module.

- **The module charges a 3.7 V lithium cell from micro-USB. A red LED shows
  charging and a green LED shows full.** Source:
  library/fm-radio-kit-manual.md, page 14. Confidence: medium.
- **The chip is probably a TP4056. Nobody has read its marking.** Source:
  library/tp4056.md. Confidence: low.

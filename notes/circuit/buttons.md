# The four buttons

- **V− is S1 on P3.1, V+ is S2 on P3.0, CH− is S3 on P5.4, and CH+ is S4 on
  P5.5. Each button pulls its pin to GND.** Source:
  datasheets/fm-radio-kit-schematic.md, zoomed reading. Confidence: medium.
- **For path A, a transistor or optocoupler that pulls the same pin to GND
  presses the button.** Source: datasheets/fm-radio-kit-schematic.md. Confidence:
  medium.

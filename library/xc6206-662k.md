# 662K (XC6206P332): 3.3 V voltage regulator

**The 662K is the 3.3 V regulator on the tuner module.** The radio block of
the kit schematic shows it as U2, with the label `662K`. The marking `662K`
usually means the XC6206P332 (3.3 V, SOT-23). No primary datasheet was
fetched: the Torex site blocks automated downloads.

- **Source:** the kit schematic (pins and role), and the secondary web page
  <https://thinklabsy.in/xc6206/> (values). The values below are
  **low confidence** until someone reads the Torex datasheet
  (<https://www.torexsemi.com/>, series XC6206).
- **Converted:** 2026-09-29.

## From the kit schematic (medium confidence)

| U2 pin in the radio block | Name | Net                                               |
| ------------------------- | ---- | ------------------------------------------------- |
| 1                         | Vin  | VCC of the tuner module (from the net VDD)        |
| 2                         | Vss  | GND                                               |
| 3                         | Vout | 3V3, which feeds the tuner chip and the STC8G1K17 |

The schematic draws the pin order 1 = Vin, 2 = Vss, 3 = Vout. The
schematic may number the symbol and not the package pins. Check the order
against the datasheet before you probe the part.

## Values from a secondary source (low confidence)

| Item                        | Value                                         |
| --------------------------- | --------------------------------------------- |
| Output voltage              | 3.3 V, ±2 %                                   |
| Maximum output current      | 200 to 250 mA                                 |
| Dropout                     | 160 mV at 100 mA (another source says 250 mV) |
| Quiescent current           | 1.0 µA typical                                |
| Input and output capacitors | 1 to 2.2 µF ceramic                           |

## What it means for the bench

- **The supply of the tuner and the microcontroller is 3.3 V,** if the
  schematic is right. The battery supply of 4.5 V (3 AAA) is above 3.3 V by
  enough margin. A 3.7 V lithium cell is above it by less than the dropout
  when the cell runs low.
- **Read the net 3V3 before the first power-on** with a multimeter and the
  HM310P current limit (`fm-radio-kit-manual.md`, conflicts).

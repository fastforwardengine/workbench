# 18650 Li-ion cell (summary)

**A protection circuit must keep the cell inside its safe voltage and
current window at every step.** The cell sets its own chemistry limits; the
charge module and the load set what actually reaches it.

## Voltage

| Value                  | Limit |
| ---------------------- | ----- |
| Nominal voltage        | 3.7 V |
| Fully charged (max)    | 4.2 V |
| Discharge cutoff (min) | 2.5 V |

## Capacity and current

- Rated capacity: 3400 mAh.
- Maximum continuous discharge current: 2000 mA (about 0.6C).
- Standard charge current: 1700 mA (0.5C). A charge current above this
  shortens the cell's cycle life.

## Discharge current through a load resistor

Use Ohm's law to size the load for a discharge test:

```
I = V / R
```

Example: a fresh cell at 4.2 V through a 4.7 ohm load draws
`I = 4.2 / 4.7 = 0.89 A`, well within the 2000 mA continuous discharge
limit. A 2 ohm load would draw 2.1 A, above the limit.

## Operating temperature

- Charge: 0 °C to 45 °C.
- Discharge: -20 °C to 60 °C.

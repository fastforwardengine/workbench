# Library

**This directory holds short datasheet summaries for one battery hardware
kit.** The agents read these files before they claim a specification. Each
file names its part, its key limits, and the formula a design needs.

These are simplified summaries for a runnable scaffold. They are not the
manufacturer datasheets. Confirm any real design against the real
datasheet.

| File                      | Part                                      |
| ------------------------- | ----------------------------------------- |
| `cell-18650.md`           | 18650 Li-ion cell                         |
| `charge-module-tp4056.md` | TP4056-based charge and protection module |
| `load-resistors.md`       | Power resistor bank, E12 series           |
| `thermocouple-k-type.md`  | K-type thermocouple                       |
| `wire-connectors.md`      | JST-PH connectors and silicone wire       |

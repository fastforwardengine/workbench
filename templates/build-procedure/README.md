# Build procedure

A starting point for the assembly of one kit. A step is small: the person
does it in a few minutes, and checks it before the next one.

1. Make a branch named for the kit, such as `fm-radio-2`.
2. Fill in `steps.md`, one section for each step. Replace each `TBD`.
3. Give each part its name, its value, and its place: the silkscreen label
   of the board.
4. Give each polarized part its orientation, and the mark that shows it.
5. Cite the datasheet in `/library` for each value and each orientation.
6. Give each step a check that the person can do, and the evidence that
   proves it: a photo, or a reading.
7. Commit, and push your branch. A push keeps the work.

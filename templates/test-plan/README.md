# Test plan

A starting point for one test plan. A plan is short and repeatable: a
technician runs it without a question.

1. Make a branch named for the test, such as `led-sweep-red`.
2. Fill in every section of `plan.md`. Replace each `TBD`.
3. Cite the datasheet in `/library` for each limit.
4. Commit, and push your branch. A push keeps the work.
